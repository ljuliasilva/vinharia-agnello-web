

                                              🍷 Vinharia Agnello 🍷

                                     --- Sistema básico de gerenciamento de Vinhos --- 
                                            
 | Uma apicação web desenvolvida para auxiliar no cadastro e na apresentação sobre vinhos da Vinharia Agnello. |



 ## 📌 Sobre o projeto

-- A Vinharia Agnello é um projeto acadêmico desenvolvido para o Checkpoint da FIAP.

-- A aplicação permite cadasrar informações básicas de vinhos, como nome, tipo, safra e quantidade de estoque, 
utlilizando HTML, CSS e JavaScript.

 ## 🎯 Objetivos

-- Cadastrar informações de um vinho;

-- Armazenar os dados utilizando variáveis JavaScript;

-- Solicitar informações por meio do prompt();

-- Exibir os dados cadastrados utilizando console.log();

-- Praticar conceitos fundamentais de lógica de programação;

-- Aplicar conceitos básicos de HTML e CSS.

=======
